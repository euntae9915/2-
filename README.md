# Claude Code 작업 폴더

- 이 폴더를 열면 아래에서 Claude Code가 저절로 실행됩니다.
- 위에 'Restricted Mode' 줄이 보이면 [Manage] -> [Trust]를 먼저 누르세요.
- 저절로 켜지지 않으면 Ctrl + ` (숫자 1 왼쪽 키) 로 터미널을 열고 claude 를 입력하세요.
- 터미널을 하나 더 열 때는 위 메뉴 [Terminal] -> [New Terminal]. 새 터미널에서는 claude 를 입력하면 켜집니다.
- 처음 실행하면 로그인을 요청합니다. (Claude Pro/Max 구독 또는 API 계정)
